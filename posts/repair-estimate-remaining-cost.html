수리비 8만 원, 이미 낸 진단비 2만 원은 또 더해야 할까요?

작성·편집: 예밍2026. 11. 07.
📌 먼저 확인할 세 가지

견적이 총액인지 앞으로 더 낼 금액인지 먼저 물어요. 이미 낸 진단비가 견적 총액에 포함됐다고 확인하면, 그 총액에서 기지급액을 빼 잔금을 구해요. 지금부터의 지출과 처음부터 쓴 합계는 칸을 나눠 비교해요.

“수리비가 8만 원이라는데, 먼저 낸 2만 원은 어디에 들어간 걸까요?”

답은 견적의 범위에 있어요. 이미 낸 2만 원까지 포함한 총액이 8만 원이면 잔금은 6만 원이에요. 2만 원과 별도로 더 내야 할 수리비가 8만 원이면 잔금도 8만 원이고요. 숫자를 더하거나 빼기 전에 어느 조건인지 확인해야 해요.

아래 금액·진단비·포함 조건과 표는 설명을 위해 직접 만든 가상 예시예요. 실제 업체의 견적이나 진단비 차감 규칙이 아니에요.

견적에 들어간 항목부터 확인해요

‘수리비’라는 한 줄에 어떤 항목을 묶었는지 살펴봐요. 부품·작업 비용 외에 점검·출장·운송·설치·회수 비용이 있는지, 부가세까지 포함한 금액인지 물어볼 수 있어요. 내 경우에 해당하지 않는 항목과 아직 모르는 항목도 나눠 적어요.

예를 들어 LG전자 요금 안내는 부품비와 수리비(기술료)를 구분하고, 출장 처리 때 출장점검료가 더해진다고 설명해요. 한 업체의 항목 구분을 참고한 것이며, 모든 업체가 같은 이름과 조건을 쓰거나 진단비를 자동으로 빼준다는 뜻은 아니에요. 아래 가상의 진단비와 이 안내의 출장점검료도 같은 항목이라고 가정하지 않아요.

수리를 맡기기로 답하기 전, 이렇게 물어볼 수 있어요. “표시된 금액이 제가 이미 낸 점검비를 포함한 총액인가요, 앞으로 추가로 낼 금액인가요? 부가세와 필요한 운송비까지 넣으면 잔금은 얼마인가요?” 답변 날짜와 항목을 함께 남기면 나중에 같은 조건을 비교하기 좋아요.

같은 8만 원 표시를 세 가지 조건으로 계산해 봐요

지금은 진단비 20,000원을 낸 뒤, 수리 진행이나 교체 구매를 결정하기 전이라고 가정해요. 이 진단비는 어느 쪽을 골라도 환불되지 않아요. 교체 구매의 최종 결제액은 75,000원이에요.

아래 수리와 교체 금액에는 각각 필요한 부가세·운송비 등 다른 비용이 모두 반영돼 있고, 별도 설치·회수 비용이나 중고 판매 수입은 없다고 가정해요. 필요한 기능을 해결하는 두 안의 비용을 비교하지만, 수리품과 새 제품의 수명·보증·상태가 같다는 뜻은 아니에요.

모든 금액은 가상 — 수리 A와 B는 서로 다른 견적 조건이에요
확인된 조건지금부터 낼 돈처음부터 합계
수리 A: 이미 낸 진단비를 포함한 총액 80,000원60,000원80,000원
수리 B: 진단비와 별도로 추가 80,000원80,000원100,000원
교체: 앞으로 결제할 총액 75,000원75,000원95,000원

A는 80,000 − 20,000 = 60,000원이 남아요. B는 추가 청구액이 80,000원이므로 거기서 진단비를 또 빼지 않아요. B의 누적 지출은 20,000 + 80,000 = 100,000원이에요. 교체도 이미 낸 진단비가 돌아오는 것은 아니므로 누적 지출은 20,000 + 75,000 = 95,000원이고요.

지금부터 낼 돈끼리 비교하면 A는 교체보다 15,000원 적고, B는 교체보다 5,000원 많아요. 처음부터 쓴 합계끼리 비교해도 차이는 같아요. 수리 누적 100,000원과 교체 잔금 75,000원을 섞으면 비교 시작점이 달라져요.

A와 B는 같은 업체에서 마음대로 고를 수 있는 할인 방식이 아니에요. 포함 여부가 다르게 확인된 두 가상 상황이에요. 실제 견적의 포함 조건이 아직 미확인이라면 어느 줄에 해당하는지부터 물어요. 이미 낸 돈과 환불 가능한 돈의 구분은 매몰 비용 글의 선납금 비교에서도 볼 수 있어요.

미확인 비용을 0원으로 바꾸지 않아요

점검 뒤 추가 작업이 필요할 수 있다는 안내를 받았다면, 지금 견적이 어디까지를 다루는지 확인해요. “어떤 작업이면 금액이 달라지나요? 추가 작업 전에 변경할 내용과 금액을 알려주실 수 있나요?”처럼 물을 수 있어요. 이것은 확인을 요청하는 문장이지 모든 업체의 절차나 법적 의무를 설명하는 말은 아니에요.

비용이 적다는 이유만으로 수리 범위까지 같다고 보지는 않아요. 어떤 증상과 기능을 다루는지, 부품 준비와 완료 예상 시점은 언제인지, 어떤 보증 조건이 적용되는지 나눠 물어요. 아직 점검하지 않은 문제나 수리 뒤의 사용 기간을 임의로 확정하지 않아요.

교체 쪽도 같은 필요를 충족하는 모델·구성인지 확인해요. 필요한 설치나 배송비가 빠져 있으면 합계를 다시 계산해야 해요. 새 제품끼리 가격을 비교할 때는 표시 가격보다 현재 결제액을 비교하는 예시를 함께 볼 수 있어요.

복사해서 쓰는 견적 비교 메모

  1. 물건과 필요한 기능: 모델 ___ / 해결할 증상·수리 범위 ___
  2. 견적 확인 시점: 확인일 ___ / 유효 기간 ___ / 아직 수리 진행 전인지 ___
  3. 이미 낸 돈: 항목·금액 ___ / 환불·포함·차감 여부와 확인한 답 ___
  4. 견적의 뜻: 총액 또는 추가액 ___ / 포함 항목 ___ / 별도·미확인 비용 ___
  5. 같은 시작점의 비교: 지금부터 수리 ___원 / 교체 ___원 / 누적 합계가 필요하면 별도 기록 ___
  6. 비용 외 조건: 필요한 기능 충족 여부 ___ / 예상 시점 ___ / 적용되는 보증 조건 ___
  7. 아직 남은 질문: 추가 작업·금액 변경 전에 확인할 내용 ___ / 받은 답 ___ / 결정·보류 상태 ___

빈칸에 답을 못 받았다면 ‘미확인’으로 남겨요. 이 메모는 견적을 같은 기준으로 읽기 위한 양식이에요. 수리 성공이나 절약액, 더 오래 쓸 수 있다는 결과를 보장하지 않아요.

자주 묻는 질문

진단비를 이미 냈으면 수리 견적에서 빼면 되나요?

자동으로 빼지 않아요. 견적이 이미 낸 진단비를 포함한 총액인지, 그와 별도로 더 낼 금액인지 확인해야 해요. 가상 예시의 80,000원이 진단비 20,000원을 포함한 총액일 때만 잔금이 60,000원이에요.

이미 낸 20,000원은 비교에서 아예 지워도 되나요?

이 예시에서는 어느 쪽을 골라도 돌려받지 못하는 공통 지출이에요. 지금부터의 추가 지출을 비교할 때 다시 더하지 않고, 처음부터 쓴 합계를 볼 때는 모든 선택에 한 번씩 더해요. 실제 견적의 환불·포함·차감 조건이 다르면 확인한 내용으로 다시 계산해요.

수리비가 새 제품값보다 낮으면 수리하는 게 맞나요?

낮은 금액은 비용 비교의 한 결과예요. 필요한 기능을 해결하는지, 어떤 수리 범위인지, 완료 시점과 보증 조건은 어떤지도 따로 확인해요. 이 글은 수리 뒤 수명이나 성공률을 계산하지 않아요.

추가 비용이 있는지 아직 모르겠다면 어떻게 적나요?

0원 대신 미확인으로 적어요. 어떤 상황에서 금액이 늘어나는지와 추가 작업 전에 무엇을 다시 확인할지 물어보세요. 답을 받기 전에는 견적 숫자를 확정된 최종 결제액으로 쓰지 않아요.

보증기간이 남았으면 수리비는 0원인가요?

기간만 보고 0원으로 확정하지 않아요. 해당 제품과 고장·서비스 항목에 어떤 조건이 적용되는지 확인해요. 보증 적용 결과를 받은 뒤 실제로 부담할 금액을 비교표에 넣어요.
