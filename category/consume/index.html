왜 자꾸 지갑이 열릴까요

할인, 무료 배송, 구독 해지… 일상 소비 속에 숨은 심리를 예밍이랑 쉽게 풀어봐요.

지금 비교하려는 것은 무엇인가요?

입력하면 계산되는 도구와 직접 조건을 적는 메모를 나눴어요. 필요한 항목을 고르면 관련 글이나 메모로 이동해요.

숫자를 넣어 비교하기

자동 계산

무료배송을 채우려고 더 담을까요?

입력: 필요한 상품값·추가 상품값·배송비·무료배송 기준

결과: 필요한 것만 살 때와 더 담을 때의 총액·차이를 보여줘요.

범위: 한 배송 묶음·모든 상품이 기준에 포함된 경우예요. 쿠폰 등은 자동 반영하지 않아요.

계산기로 가기 → 자동 계산

1+1·대용량, 쓸 양까지 보면 어떨까요?

입력: 두 상품의 결제액·총량·예상 사용량·같은 종류의 단위

결과: 받는 양과 쓸 양 기준의 단가, 남을 것으로 본 양을 보여줘요.

범위: 사용량은 직접 예상한 값이에요. 품질·배송비·할인 조건을 자동 판정하지 않아요.

계산기로 가기 → 자동 계산

다음 달 구독과 단건 이용, 얼마씩 낼까요?

입력: 다음 한 달 구독료·예상 이용 횟수·단건 가격

결과: 구독료와 같은 횟수의 단건 이용 비용을 비교해요.

범위: 같은 이용을 단건 구매할 수 있어야 해요. 연간 선결제·환불·위약금은 제외해요.

글 상단의 ‘내 이용 계획으로 다음 달 구독 비용 비교하기’를 누르면 계산기로 내려가요.

글에서 계산기로 이동하기 →

조건을 직접 적어 비교하기

직접 적는 메모

월간·연간 구독, 첫 계약의 총액은?

준비: 같은 기능의 요금·비교 기간·결제 횟수 계획·청구 조건

적을 내용: 월간 총액과 연간 청구액·전체 약정액을 나눠 직접 정리해요.

범위: 첫 12개월의 가상 비용 비교예요. 실제 중단·환급·기능 차이는 따로 확인해요.

메모로 가기 → 직접 적는 메모

쿠폰을 쓰면 최종 결제액은 얼마일까요?

준비: 상품·수량, 쿠폰 대상·순서·한도·최소금액, 추가 구매·배송비

적을 내용: 원래 주문과 쿠폰 사용 주문의 총액·차이를 직접 적어요.

범위: 쿠폰 적용 가능 여부와 계산 규칙은 판매처에서 확인해요. 자동 판정기가 아니에요.

메모로 가기 → 직접 적는 메모

할인과 포인트, 같은 기간에 얼마를 쓸까요?

준비: 필요한 구매 목록·기간, 오늘 결제액, 쓸 포인트와 사용 조건

적을 내용: 같은 기간의 결제 합계·미사용 잔액·추가 구매를 나눠 적어요.

범위: 적립 예정액을 오늘 할인으로 빼지 않아요. 사용 가능 여부를 자동 판정하지 않아요.

메모로 가기 → 직접 적는 메모

한곳에 모을까요, 나누어 주문할까요?

준비: 같은 제품·규격·수량, 배송 묶음별 상품값·내 주소의 배송비·기준

적을 내용: 묶음별 결제액을 적고 주문안 전체 합계를 비교해요.

범위: 합배송·무료배송·할인 조건은 주문서에서 확인해요. 메모가 자동 판정하지 않아요.

메모로 가기 →
